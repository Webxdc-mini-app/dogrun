# ドッグラン Dog Run

Delta Chatのチャットで犬を育て、参加者同士で遊べるwebxdcアプリです。ブラウザーだけで操作を試せるデモにも対応しています。

- 最新版：**1.1.1**
- README更新日：2026年10月18日

## すぐに使う

### ブラウザーでデモを開く

1. [index.html](index.html) をパソコンに保存します。
2. 保存したファイルをブラウザーで開きます。追加ファイルやインストールは不要です。
3. 最初からいる「ココ」と「マロン」を選び、お世話やボール遊びを試します。

「デモの操作役」で「あおい」「さくら」を切り替えると、それぞれの飼い主として操作できます。「デモを最初から」を押すと、デモの記録を初期状態に戻せます。

操作内容は使用中のブラウザーに保存します。保存が禁止されている場合は、画面を閉じると失われます。ブラウザーのデータ削除やファイルの保存場所の変更によって、以前の記録を読み込めなくなることもあるため、必要なデータは書き出してください。

**デモの記録は別端末やDelta Chatへ自動では共有されません。**

通常のウェブサーバーに配置した場合は、`index.html?demo=1` でデモを開けます。Delta Chatの共有APIが利用できる場合は、共有モードが優先されます。

### Delta Chatで一緒に遊ぶ

1. [dogrun-1.1.1.xdc](dogrun-1.1.1.xdc) をダウンロードします。
2. 一緒に遊ぶ相手がいるチャットまたはグループへ、ファイルとして1回送信します。
3. 全員が**その同じ投稿**からアプリを開きます。
4. 各参加者が「+ 新しい犬」から自分の犬を迎えます。
5. 公園や犬の一覧から相手の犬を選び、遊びます。

同じファイルを別の投稿として送ると、別の遊び場になります。同じアカウントの連携端末は同じ飼い主として扱われます。

## 主な操作

| 操作 | 内容 |
| --- | --- |
| 新しい犬 | 名前・犬種・性格を選んで迎える。自分の犬は3頭まで |
| おやつ | お腹と元気が回復。お腹が85を超えると押せない |
| なでなで | ごきげんやなつきが上がる |
| ブラッシング | 自分の犬をきれいにする |
| ボール遊び | ごきげんが上がり、元気を消費する |
| 帰宅／ランに送る | 自分の犬を休ませる／公園へ戻す |
| 手紙 | 相手の犬へ手紙や品物を届ける |
| 郵便受け | 自分の犬に届いたお届けを読む |
| データ引き継ぎ | 自分の犬の書き出し・読み込み |

状態は時間とともに変化します。帰宅中は元気が回復しますが、お腹は減ります。公園のごはん場へ歩くだけでは自動で満腹にはなりません。

犬の走る位置や動きは端末ごとに異なります。お世話やお届けの情報が共有されます。

## バージョンをまたいでデータを引き継ぐ

### 1. 移行前の版で書き出す

1. 「データ引き継ぎ」→「自分の犬を書き出す」を押します。
2. Delta Chatでは「ファイルをチャットへ保存」を押し、送信画面で保存先を確認して送信を確定します。
3. ブラウザーデモでは「ファイルを端末に保存」でJSONファイルをダウンロードします。
4. または「全文を選択」からデータをコピーし、全文を保存します。

### 2. 新しい版で読み込む

1. 新しい版を共通のチャットへ1回送信し、全員が同じ投稿から開きます。
2. 新しい犬を迎える前に「データ引き継ぎ」を押します。
3. 保存したJSONファイルを選ぶか、保存したデータの全文を貼り付けます。
4. 「内容を確認」で犬の名前・頭数・レベルを確認します。
5. 「この内容を引き継ぐ」を押し、一覧で自分の犬になったことを確認します。
6. 他の参加者も、それぞれ自分のデータを読み込みます。

### 引き継ぎの範囲と注意

- 自分の犬の名前・犬種・性格・経験値・状態・公園／おうちの情報を引き継ぎます。
- 自分の犬に関係するお届けは、容量内の**最新最大500件**を書き出します。容量を超える場合は古い記録から除きます。
- お届けは、送り主と宛先の両方の犬がそろうと表示されます。
- 同じ犬は重複登録しません。既にいる犬の状態を優先し、古いデータで経験値を巻き戻しません。
- 自分の犬が合計3頭を超える読み込みや、別の参加者が登録済みの犬の読み込みはできません。
- 未読の印や画面上の走る位置は引き継ぎません。経過時間による状態変化は続きます。
- 移行中は旧版でのお世話を控え、全員で新しい投稿にそろえてください。
- 元の投稿とバックアップは残してください。

引き継ぎ形式は `dogrun-personal-backup`、`schema: 1` です。今後の版でも、この形式の読み込み対応を維持する必要があります。

### 1.0.2以前からの救出

1.0.0・1.0.1・1.0.2には書き出しボタンがありません。新しい投稿から旧投稿のデータを直接読むこともできません。

PCで旧アプリ自身の開発者ツールのConsoleを開ける場合は、[旧版データ救出スクリプト](DogRun_旧版データ救出.js) を使用できます。**ファイルを直接実行せず、テキストエディターで開いて内容をコピーし、旧アプリのConsoleで実行します。** 表示されたデータの全文を保存し、新しい版で読み込んでください。

詳しい手順は操作マニュアルの11章を参照してください。Consoleを開けない環境では、この方法での救出はできません。元の投稿を残して利用してください。

## 手紙とバックアップの扱い

手紙はチャット内で共有されるアプリのデータです。特定の相手だけが読める秘密のメッセージとしては使わないでください。

バックアップには手紙の本文が含まれます。自分のデータを自分で保管し、読み込みも本人が行ってください。バックアップは本人確認を保証する仕組みではありません。

## 困ったとき

| 状況 | 対処 |
| --- | --- |
| 共有機能を読み込めない | Delta Chatでは元のアプリ投稿から開き直す。通常のブラウザーでは最新版のHTMLをローカルで開くか、`?demo=1` を付ける |
| 相手の犬がいない | 同じチャットの同じ投稿か確認し、通信の反映を待つ。相手の犬が帰宅中でないかも確認する |
| デモのデータが消えた | 同じブラウザー・同じ保存場所で開いているか、保存が許可されているか確認する |
| 犬を追加できない | 帰宅中を含めて、自分の犬は3頭まで |
| おやつが押せない | お腹が85以下になるまで待つ |
| 手紙を送れない | 自分の犬を迎え、手紙の本文を入力する |
| 引き継ぎデータが読み込めない | 正しいJSONファイルまたは全文か、頭数上限や所有者の競合がないか確認する |
| ボタンが見えない | 下へスクロールする。犬の一覧は横にもスクロールできる |
